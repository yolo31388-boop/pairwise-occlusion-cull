# pairwise-occlusion-cull

室外大场景一开镜，GPU 遮挡剔除把整座山误判成被挡住：Hi-Z 金字塔只做了单层，深度比较用了上一帧的 mip；包围盒投影到屏幕后没有按最近深度取保守值；相机快速平移时上一帧的遮挡结果直接复用，山体边缘闪一下又出现；透明物体和粒子没有写入深度，被错误剔除；多视图渲染时 Hi-Z 只按主视图构建，VR 右眼丢物体；遮挡回读延迟两帧，角色从掩体后出来时先消失再出现。render/occlusion_cull.py 是核心，tests/test_occlusion_cull.py 15个红。要修的是：构建完整 Hi-Z 金字塔；包围盒用最近深度做保守测试；相机移动时失效上一帧结果；透明/粒子单独通道；多视图分别构建；延迟回读做时间重投影。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
